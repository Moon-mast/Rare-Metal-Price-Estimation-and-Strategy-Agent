稀有金属价格预估与策略 Agent

面向稀有金属与关键矿产，在供给高度集中、政策冲击频繁、价格传导非线性（"火箭—羽毛"式）的市场约束下， 生成可追溯、可证伪、可执行的价格情景与买卖策略框架。不输出单点价格，只输出情景、区间、概率与证伪条件。

市场状态识别供给集中度 HHI库存分位 期限结构 / 内外价差三情景 + 概率仓位量化规则证伪条件
⚠ 实时信息获取：开启输入框左侧「联网工具」后，模型可自动联网搜索（多引擎回退）、读取网页正文并精确计算—— 智谱 GLM 内置服务端搜索开箱即用；其他提供方需先在本地运行 node agent-proxy.js（见 README）。关闭工具时请把最新数据贴进对话， 缺失维度会被显式标注并下调置信度；信息不足时 Agent 会输出"不足以形成策略建议"及最小数据清单。
